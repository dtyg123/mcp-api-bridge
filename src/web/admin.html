添加 OpenAPI 服务

读取 OpenAPI 3.x 或 Swagger 2.0 文档（Swagger 2.0 自动转换），每个 operation 变成一个工具。它只是来源；在「输出」里选择发布形态并裁剪工具。
凭证（可多选；在下方「🔑 全局凭证」卡片里新建 / 轮换，请求头名取自凭证自身）
高级选项（额外请求头 / 过滤 / 超时）

一键导入

粘贴任意一种即可：MCP 客户端配置（{ "mcpServers": { ... } }，支持批量）、OpenAPI / Swagger 文档（JSON 或 YAML 正文）、文档 URL，或一条启动命令（如 npx -y @scope/server）。 导入后会自动生成一个同名输出。
🔑 全局凭证（认证信息）
这是所有来源共用的凭证库。新建后，在上方对应来源表单的「复用认证信息」里勾选，MCP / REST / 接口测试才会自动带上；也可以在来源表单的「鉴权凭证」里按文档方案名直接填。

输出

输出是对外发布的一套端点：挑来源、裁工具、选形态（MCP / API），一个输出可以组合多个来源。 「转换」把工具名统一成 {source}__{tool}；「镜像」保持 MCP 原名；「原样透传」按上游路径转发 API 请求。
